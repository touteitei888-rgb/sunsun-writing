> 一张海报，300 dpi。
>
> 印出来 8 块钱。
>
> 为这 8 块钱，我们开了四次会。

上面这四行不是文案，是给模型听的调子。

`baimiao-cold-writing` 是一个 Agent Skill。它管三件事：只写看得见的东西，只用量得出来的说法，把该读者补的部分留给读者。

它不生产金句。它删掉你稿子里那些"那一刻我明白了"。

## 先看两版

模型默认会这么写离职：

> 走出园区大门，我心里五味杂陈。这三年有不舍，也有期待，感谢一路同行的伙伴，愿未来可期。

四个成语，零个事实。

按本 skill 改出来：

> 办离职要还三样东西：门禁卡、耳机、抽屉钥匙。
>
> 钥匙配过，两把。我交了一把。
>
> 行政数了数，说行。

"说行"这两个字，把这家公司怎么看待人讲完了。全文没有一处心情。

## 十四招

招式列在下面。它们是工具箱，不是打卡表。

| 招式 | 干什么用 |
| :--- | :--- |
| **白描** | 只留可观察项：动作、对话、数字、物件、环境 |
| **对照** | 把 300 dpi 和 8 块钱并排放，然后闭嘴 |
| **数字锚定** | "第 11 版"顶掉"改了很多次"，"十一点"顶掉"很晚" |
| **反复与断裂** | 前四次都答"我说好"，第五次换成"我看看排期" |
| **称谓滑动** | 李老师 → 老师 → 名字 → 交接通知上的全称 |
| **伏笔照应** | 写着"周三交稿"的便利贴，第二个月还在原处 |
| **物件承重** | 不便开口的话，交给气泡袋、药盒、胶印 |
| **旁观者** | 保洁照擦两遍门，行政数了数说行 |
| **临床自察** | 唯一能写身体的地方：按住手腕数脉搏，数了两遍 |
| **时间跳切** | 四年砍成三段，一把钥匙那一瞬逐帧放 |
| **留白** | 人物没答的，文本不替他答 |
| **反高潮** | 领奖开场，18 块到付运费和一只气泡袋收场 |
| **缺席** | 开业两百人，第三天只剩卷帘门的声音 |
| **回环** | 结尾再报一次 300 dpi，重量已经换了 |

白描是常驻，其余看材料给不给。全用上，稿子会挤。

## 冷硬引擎

写小说或硬派叙事时，在白描之上再装一套引擎：叙述者是一个手里有顶级资源、心里有刻度的执行者，用成本和效率衡量一切，**但在关系里处于被动服从的位置**。

最后半句是刀柄。一个不能说"不"的人只能靠记账活着，她每一次"我说好"都在给读者攒重量。

五条要求：只允许可测量的东西进文本（金额、押金、限额、体重、收缩压、到分钟的时间、楼层公里数）；戏剧性事件之后只写她先做什么；贯穿件是一个职业动作（编号、贴标签、称重、归档、对账）；跳掉最贵的过去；关键节点放一个绝对理性的他者——模型、精算表、理赔条款——它不评判、不劝、不为难，回话永远比人快，于是机器显得比她有分寸。

仓库里附两篇完整范文和刀口标注：《四十八个标签》（执行者视角，伴侣最后十二天）、《六十四道》（女方视角，被调查的人才是写档案的人）。详见 [references/cold-executor.md](./references/cold-executor.md)。

## 三条门规

> 动作能承担的地方，不写心理。
>
> 物件能承担的地方，不下结论。
>
> 前文能捡回来的地方，不另起一段抒情。

另有一条底线，专治非虚构：**数字不许编。**

"两把钥匙"之所以扎人，是因为真的配过两把。想不起来就写"记不清"。模型顺手补一个更漂亮的数，整篇的可信度就跟着那个数一起塌。

模型没在场。它不该替你回忆。

## 体检脚本

"克制"很容易被当成玄学，所以这套写法的阈值是量的，并且配了一把能跑的尺子。

```bash
node scripts/style_check.mjs draft.md
```

零依赖，Node 18 起。它输出四块内容：总分、硬红线逐条定位（第几段、命中什么、该换成什么）、与基线的节奏偏差、结尾有没有接住开头。

```text
文风体检  97/100   可以交付
【硬红线】 0 处
【首尾闭环】 ✓ 回扣开头
```

同一份典型的 AI 腔稿子丢进去，出来 51 分、13 处红线，其中一条长这样：

```text
[元叙事] 第2段｜…然而回望来路，我终于明白…
   → 删掉总结句，让前文的事实自己承担意义
```

红线分六类：情绪直陈、抒情成语、AI 套话、元叙事、情感归因与动机自白（"我之所以""因为我害怕"）、替读者提问（"你有没有想过""换成是你"）。外加格式类硬约束：感叹号、省略号、加粗、小标题、bullet、引号对话、三连同构排比。

词表做过反向校准——把基线语料喂回去必须 100 分、0 红线，否则说明词表里混进了正常中文常用词（"最后"就是被踢出去的一个，它是时间词，不是套话）。

## 使用

点名调用：

```text
用 $baimiao-cold-writing 拿我这段经历写一篇不煽情、但留得住人的稿子。
```

讲人话也行：

```text
这段改成白描，别替我难受，让动作和数字自己说。
这条小红书压到 150 字，一句一段，不要 emoji。
我这篇复盘感悟太多了，帮我删掉一半句子，剩下的换成事实。
```

吃什么材料：

- 你自己经历过、细节可核对的事
- 人物稿、回忆性写作、非虚构
- 创业、职场、家庭、关系
- 作品集项目说明、设计决策记录
- 已经写完但读起来像宣传稿的旧稿

不吃什么：

- 公文、接口文档、周报
- 手上没有任何具体细节，只想要"文学感"
- 需要喊人下单的营销文案
- 拿真实在世的人编私密情节（这条是硬边界，脚本不管，规矩管）

材料里没有的数字，它不填。材料里没有的空场，它也不给你扫一个出来。

## 数据从哪来

基线取自一份 6.5K 字、272 段的中文第一人称克制长文，逐段统计后写回脚本常量：

| 指标 | 基线 |
| :--- | :--- |
| 段长中位 | 15 字 |
| ≤12 字段落占比 | 44.1% |
| 句长中位 | 13 字 |
| 数字标记 | 2.45 个/百字 |
| 对话独立成段占比 | 30.1% |
| 分节符 | 0.77 个/千字 |
| 问号 | 0.77 个/千字 |
| 感叹号 / 省略号 | 0 / 0 |

语料本身不进仓库，仓库里也没有任何一篇原文的复现。统计口径、复算命令和踩过的坑写在 [references/baseline.md](./references/baseline.md)，任何人都能用自己的语料重算一遍。

## 关于立场

这是一份写作技法整理，研究对象是句式与节奏，不是任何一篇文章的八卦，也不是任何真实人物。文中示例句子全部为本仓库自造。

技法分类这个方向，社区里早有同类整理工作，本仓库在思路上受过公开讨论的影响；正文、脚本、数据口径、示例全部独立成稿，与任何既有仓库不存在文本对应关系。

判断真假不是这个项目的事。它只关心：这句话该不该写出来。

## 反馈

模型会复发。最典型的复发是稿子写到第九段，它突然来一句：

> 那一刻，我终于懂了。

遇到这种，欢迎开 Issue。请带上：

- 原始材料（能脱敏就脱敏）
- 模型和调用方式
- 它产出的片段
- `style_check.mjs` 的完整报告
- 从第几段开始，它替你多愁善感了

MIT 协议，随便改，改完记得留一行版权头。
