> 一颗卵子，三点五微克。
>
> 五千万美元现金，两点五吨。
>
> 一段沉默，十一秒。

这三行不是这里写的。它们来自《我的女友景甜》。

整个仓库里，原文只出现这一次，就是上面这三行。

剩下的全是量得出来的东西：段长中位数、数字密度、六类禁词、一把能跑的尺子。

`sunsun-writing` 是一个 Agent Skill。它把孙宇晨那篇刷屏长文里能拆的写法拆成十四招，再往里装一套写给小说用的冷硬引擎。

装上以后，模型不会变成孙宇晨。

它不会有五千万美元，也不会突然需要飞一趟大西洋。

它只会在写到第九段、正要开口说"我终于明白了"的时候，闭嘴。

## 先看一段

普通模型写离职：

> 走出园区大门的那一刻，我心里五味杂陈。三年的青春在身后缓缓落幕，感谢一路同行的伙伴，愿未来可期。

四个词：五味杂陈、青春、落幕、未来可期。

零个事实。

按本 skill 改出来：

> 办离职要还三样东西：门禁卡、耳机、抽屉钥匙。
>
> 钥匙配过，两把。我交了一把。
>
> 行政数了数，说行。

全文没有一处心情。

"说行"这两个字，把这家公司怎么看待人讲完了。

## 十四招

| 招式 | 它怎么下手 |
| :--- | :--- |
| **白描** | 不写"心如刀割"。写"我把袖子往上卷了一下" |
| **对照** | 300 dpi 和 8 块钱并排放，然后闭嘴，谁也不替谁解释 |
| **数字锚定** | "改了很多次"换成"第 11 版"，"很晚"换成"十一点四十" |
| **反复与变奏** | 前四次都答"我说好"，第五次让"我看看排期"进场 |
| **称谓滑动** | 李老师 → 老师 → 名字 → 交接通知上的全称 |
| **伏笔与照应** | 写着"周三交稿"的便利贴，第二个月还在原处。中间不举"这是伏笔"的牌子 |
| **物件叙事** | 人不方便开口的时候，让气泡袋、药盒、胶印代班 |
| **旁观者** | 保洁把门擦了两遍，行政数了数说行 |
| **临床自察** | 唯一允许写身体的地方：按住自己手腕数脉搏，数了两遍 |
| **时间跳切** | 四年砍成三段，钥匙落地那一秒逐帧放 |
| **留白** | 人物没答的那一句，文本不替他答 |
| **反高潮** | 领奖开场，18 块顺丰到付和一只气泡袋收场 |
| **缺席** | 开业两百人，第三天只剩卷帘门的声音 |
| **回环** | 结尾再报一次 300 dpi，重量已经换了 |

白描每次都在，其余看材料给不给。

十四招全塞进去，稿子会挤。

还有一条不算招式的：**段长中位数 15 字**。

它不上台面，但它管着前面所有招的呼吸。招式学会了、段落还是长，读起来一样是 AI。

## 冷硬引擎

写小说和硬派叙事时，在白描之上再装一套引擎。

叙述者是一个手里有顶级资源、心里有刻度的执行者，用成本和效率衡量一切，**但在关系里处于被动服从的位置**。

最后半句是刀柄。

一个不能说"不"的人只能靠记账活着。她每一次"我说好"，都在给读者攒重量。

五条要求：

只允许可测量的东西进文本——金额、押金、限额、体重、收缩压、到分钟的时间、楼层和公里数。

戏剧性事件之后，只写她先做什么，不写她怎么想。

贯穿件必须是一个职业动作：编号、贴标签、称重、归档、对账。

跳掉最贵的过去。全文不提那一年是怎么开始的。

关键节点放一个绝对理性的他者——模型、精算表、理赔条款。它不评判、不劝、不为难，回话永远比人快，于是机器显得比她有分寸。

仓库里附两篇完整范文和刀口标注：《四十八个标签》（执行者视角，伴侣最后十二天）、《六十四道》（女方视角，被调查的人才是写档案的人）。

详见 [references/cold-executor.md](./references/cold-executor.md)。

## 三条门规

> 动作能承担的地方，不写心理。
>
> 物件能承担的地方，不下结论。
>
> 前文能捡回来的地方，不另起一段抒情。

非虚构再加一条：**数字不许编。**

"两把钥匙"扎人，是因为真的配过两把。

想不起来就写"记不清"。模型顺手补一个更漂亮的数，整篇的可信度会跟着那个数一起塌。

模型不在现场。它不该替你回忆，更不该替你记时间。

## 一把能跑的尺子

"克制"很容易被当成玄学，所以这里的阈值全部是量的，并且配了一把能跑的尺子。

```bash
node scripts/style_check.mjs draft.md
```

零依赖，Node 18 起，不需要 Python，不需要 `npm install`。

它输出四块：总分、硬红线逐条定位（第几段、命中什么、该换成什么）、与基线的节奏偏差、结尾有没有接住开头。

一份按本 skill 写出来的稿子：

```text
文风体检  97/100   可以交付
【硬红线】 0 处
【首尾闭环】 ✓ 回扣开头
```

同一件事用典型 AI 腔写一遍丢进去：51 分，14 处红线。其中一条长这样：

```text
[元叙事] 第2段｜…然而回望来路，我终于明白…
   → 删掉总结句，让前文的事实自己承担意义
```

红线六类：情绪直陈、抒情成语、AI 套话、元叙事、情感归因与动机自白（"我之所以""因为我害怕"）、替读者提问（"你有没有想过""换成是你"）。

外加格式类硬约束：感叹号、省略号、加粗、小标题、bullet、引号对话、三连同构排比。

词表做过反向校准：把基线语料整份喂回脚本，必须 100 分、0 红线。达不到，说明词表里混进了正常中文常用词。

"最后"就是被踢出去的一个。它是时间词，不是套话。

## 数据从哪来

基线来自那份长文的正文，6457 字、272 段、411 句，逐段量完之后写回脚本顶部的 `BASELINE` 常量：

| 指标 | 基线 |
| :--- | :--- |
| 段长中位 | 15 字 |
| ≤12 字段落占比 | 44.1% |
| 句长中位 | 13 字 |
| 数字标记 | 2.45 个/百字 |
| 对话独立成段占比 | 30.1% |
| 分节符 | 0.77 个/千字 |
| 问号 | 0.77 个/千字 |
| 感叹号 / 省略号 | 0 / 0 |

感叹号和省略号都是 0。

这不是巧合。那是这篇文章里最硬的一条自我约束：停顿用句号，不用"……"。

统计口径、复算命令、踩过的四个坑写在 [references/baseline.md](./references/baseline.md)。

任何人都能换一份语料重算一遍。这套阈值不是权威，是一把可以被推翻的尺子。

## 使用

点名调用：

```text
用 $sunsun-writing 拿我这段经历写一篇不煽情、但留得住人的稿子。
```

讲人话也行：

```text
按《我的女友景甜》那种白描和留白的感觉改一下这段。
别替我难受，让动作和数字自己说。
这条小红书压到 150 字，一句一段，不要 emoji。
我这篇复盘感悟太多了，帮我删掉一半句子，剩下的换成事实。
```

吃什么材料：

- 自己经历过、细节可核对的事
- 人物稿、回忆性写作、非虚构
- 创业、职场、家庭、关系
- 作品集项目说明、设计决策记录
- 已经写完但读起来像宣传稿的旧稿

不吃什么：

- 公文、接口文档、周报。接口没有白月光
- 手上没有任何具体细节，只想靠换行制造文学感
- 需要喊人下单的营销文案
- 拿真实在世的人编私密情节（这条是硬边界，脚本不管，规矩管）

材料里没有的数字，它不填。

材料里没有海，它也不会给你挖一片出来。

## 引用与立场

本仓库是独立的写作技法研究，与孙宇晨、景甜及文中出现的任何人物没有关联，不代表任何一方的立场。

开头那三行是从原作开头搬来的数字梗，一共 27 个字，是全仓库唯一的引用，用途是交代方法来源。

除此之外零重合：拿仓库里每份文件做中文 8 字滑窗比对，5 处命中全部落在三、五两句的接缝上（原文里"三点五微克"和"五千万美元现金"本来就前后挨着），其余十份文件命中 0 处。比对口径写在 [references/baseline.md](./references/baseline.md)，任何人都能重跑一遍。

法院在判的事，一个 README 不掺和。判断真假不在这个项目的能力范围里。

它只关心：这句话该不该写出来。

把这类写法拆成可教的招式，社区里做得更早、也更完整的是 [KKKKhazix/sun-style-writing](https://github.com/KKKKhazix/sun-style-writing)（MIT）。本仓库的招式划分和"门规"这条思路受它影响，特此说明。招式表、全部示例句子、冷硬引擎、体检脚本、数据口径均为独立撰写与实现。

## 反馈

模型会复发。

最典型的复发是稿子写到第九段，它突然来一句：

> 那一刻，我终于懂了。

看到这句，欢迎开 Issue。

请带上：

- 原始材料（能脱敏就脱敏）
- 模型和调用方式
- 它产出的片段
- `style_check.mjs` 的完整报告
- 从第几段开始，它替你多愁善感了

MIT 协议，随便改，改完记得留一行版权头。

三点五微克不随许可证分发。
